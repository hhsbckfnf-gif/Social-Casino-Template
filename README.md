# Social Casino Hub

Social Casino Hub is a modern free-to-play social casino entertainment website for users 18 and older. The site offers casino-style games for fun only, with no real-money wagering, deposits, withdrawals, or cash prizes.

## Tech Stack

- Vite
- React
- TypeScript
- shadcn-ui
- Tailwind CSS

## Local Development

```sh
npm install
npm run dev
```

## Verification

```sh
npm run lint
npm run test
npm run build
```

## Vercel Deployment

Recommended Vercel settings:

- Framework Preset: Vite
- Install Command: npm install
- Build Command: npm run build
- Output Directory: dist
